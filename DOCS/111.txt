The Diagnosis: The Missing "Golden Record" Path for Direct Charges

Your system has two distinct payment paths, but only one of them is currently wired up to record transactions in Firestore.

The Connect Payment Path (Moon Tide - WORKING):

Flow: Customer pays -> stripe-checkout.js calls /record-and-distribute-transaction -> main.py creates the "Golden Record" and saves it to Firestore.

Result: Transactions for Store Owners like Moon Tide are correctly recorded in the database.

The Direct Payment Path (AARIE.ca - FLAWED):

Flow: Customer pays -> checkout.html's JavaScript completes the payment.

The Bug: The success logic in checkout.html does not call any backend endpoint to record the transaction. It simply shows a success message.

Result: The payment exists in Stripe, but your backend is never notified, so no "Golden Record" is ever created in your Firestore customers or clients/{uid}/transactions collections.

You are seeing the transaction in Stripe because the payment part worked. You are not seeing it in Firestore because the "record-keeping" step was never triggered for direct charges.

// ========================================
// RECORD AARIE.CA TRANSACTION (NEW)

async function recordAarieTransaction(data) {
    try {
        // This payload matches what the orchestrator endpoint expects
        const payload = {
            stripePaymentId: data.stripePaymentId,
            name: data.name,
            email: data.email,
            phone: data.phone,
            items: [{
                id: data.product.id,
                name: data.product.name,
                price: data.product.price / 100, // Convert cents to dollars for consistency if needed, or keep as cents
                quantity: 1,
                image: '' // No image for this package
            }],
            workshopId: null,
            workshopDetails: {}
        };

        const response = await fetch(`${BACKEND_URL}/record-and-distribute-transaction`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(payload)
        });

        if (response.ok) {
            console.log('[Checkout] AARIE.ca transaction recorded successfully via orchestrator.');
        } else {
            // Throw an error to be caught by the calling function
            const errorData = await response.json();
            throw new Error(errorData.error || 'Failed to record transaction.');
        }
    } catch (error) {
        console.error('[Checkout] Error in recordAarieTransaction:', error);
        // Re-throw to allow the caller to handle the non-blocking nature
        throw error;
    }
}
