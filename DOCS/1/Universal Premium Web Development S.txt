Core Commandments
1. NEVER Ship Mediocrity
"Good enough" is failure with better PR.

Every website must evoke emotion. Users should feel something before they read a single word. The bar is not "functional" — the bar is breathtaking.

2. Dark Theme is Default Premium
Light themes are for documentation sites and medical apps. Premium brands — Apple, Tesla, Netflix, Spotify — understand that darkness creates drama, focus, and sophistication.

/* Universal Dark Theme Foundation */
:root {
  --bg-primary: #141419;      /* Near-black with warmth */
  --bg-secondary: #1a1a22;    /* Cards, elevated surfaces */
  --bg-tertiary: #242430;     /* Inputs, subtle containers */
  
  --text-primary: #ffffff;
  --text-secondary: rgba(255, 255, 255, 0.7);
  --text-muted: rgba(255, 255, 255, 0.4);
  
  --accent-primary: #d4a017;  /* Gold - luxury, CTAs */
  --accent-glow: rgba(212, 160, 23, 0.4);
}
body {
  background: var(--bg-primary);
  color: var(--text-primary);
}
3. Signature Accent Strategy
Choose ONE accent color and make it sacred:

Gold → Luxury, wealth, premium
Electric Blue → Tech, innovation, trust
Deep Purple → Creativity, royalty, mystery
Coral/Salmon → Warmth, approachability, modern
Usage Rules:

Headlines (as gradients)
CTAs and primary buttons
Hover states
Focus rings
Key badges and highlights
Glowing effects
Never:

Background colors for large areas
More than 20% of visual weight
Combined with another accent

4. Parallax (JavaScript)
// Universal Parallax Pattern
window.addEventListener('scroll', () => {
  const scrollY = window.scrollY;
  
  document.querySelectorAll('[data-parallax]').forEach(el => {
    const speed = el.dataset.parallax || 0.3;
    el.style.transform = `translateY(${scrollY * speed}px)`;
  });
}, { passive: true });
<!-- Usage -->
<div data-parallax="0.3">Slow parallax</div>
<div data-parallax="0.5">Medium parallax</div>

Quality Checklist
Before shipping ANY project:

 Hero makes visitors say "wow"
 All text is perfectly readable
 Dark theme with warm undertones
 Signature accent color used strategically
 Typography from Google Fonts (3 families max)
 Glassmorphism on cards/nav
 Entrance animations on major elements
 Hover effects on all interactive elements
 Parallax somewhere on page
 Scroll-aware navigation
 Premium shadows with colored glows
 Gradient text on headlines
 Smooth scrolling enabled
 Custom scrollbar styled
 Mobile responsive and tested
 Loading states are premium (not just spinners)
 Empty states have personality
 60fps animations (only animate transform/opacity)
Technology-Specific Notes
Plain HTML/CSS/JS
Use CSS custom properties for theming
Use Intersection Observer for scroll animations
Use <template> tags for component patterns
React/Vue/Svelte
Use CSS Modules or styled-components
Create reusable animation hooks
Lazy load images and components
WordPress/Shopify
Override theme with custom CSS
Use Advanced Custom Fields for content
Custom JavaScript for interactions
Next.js/Nuxt
Use CSS Modules with global theme
Server components for static content
Client components for interactivity
This standard applies regardless of technology. The framework is a tool. Excellence is the product.
