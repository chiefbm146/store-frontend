This is a brilliant workflow. You are describing a "Claim Code" system.

It solves the biggest bottleneck you have right now: Manual Admin Work. Instead of you manually copy-pasting UIDs into Python files, the user "claims" the store themselves using a secure PIN you gave them.

Here is the exact architecture to automate this fully.

The New Flow

You generate a random PIN (e.g., 8392) and save it to the Store's config in the database.

Client goes to the Portal, enters 8392.

Client signs in with Google.

Backend finds the store with PIN 8392 and stamps the Client's UID onto the store's ownerUid field automatically.

Client is redirected to Dashboard (which now shows their store because the UID matches).

Client clicks "Setup Stripe".

Backend creates the Stripe account and stamps the new stripeAccountId onto the store's paymentConfig.

You never have to touch the code to onboard a client again.

@client_api.route('/claim-store', methods=['POST'])
@verify_firebase_token
def claim_store():
    """
    Links an authenticated user to a store using a secret PIN (Claim Code).
    """
    user_uid = request.user_uid
    data = request.json
    pin = data.get('pin')

    if not pin:
        return jsonify({'error': 'PIN is required'}), 400

    logger.info(f"Store Claim Attempt: User {user_uid} trying PIN {pin}")

    try:
        # 1. Find the store with this PIN
        # Note: In Firestore, we query for where storeInfo.claimCode == pin
        query = db.collection('stores').where('storeInfo.claimCode', '==', pin).limit(1).stream()
        
        target_store_doc = None
        for doc in query:
            target_store_doc = doc
            break
        
        if not target_store_doc:
            logger.warning(f"Store Claim Failed: Invalid PIN {pin}")
            return jsonify({'error': 'Invalid PIN. Please check and try again.'}), 404

        store_data = target_store_doc.to_dict()
        store_id = target_store_doc.id
        current_owner = store_data.get('storeInfo', {}).get('ownerUid')

        # 2. Security Check: Is it already claimed?
        if current_owner and current_owner != 'unclaimed' and current_owner != user_uid:
            logger.warning(f"Store Claim Failed: Store {store_id} already owned by {current_owner}")
            return jsonify({'error': 'This store has already been claimed.'}), 409

        # 3. LINK THE USER: Update the store with the user's UID
        # We also remove the PIN so it can't be reused/guessed easily later (optional security)
        db.collection('stores').document(store_id).update({
            'storeInfo.ownerUid': user_uid,
            'storeInfo.claimCode': firestore.DELETE_FIELD # Optional: delete pin after use
        })

        logger.info(f"✅ Store Claim Success: User {user_uid} is now the owner of {store_id}")
        return jsonify({'success': True, 'storeId': store_id, 'message': 'Store successfully linked!'}), 200

    except Exception as e:
        logger.error(f"Error claiming store: {e}", exc_info=True)
        return jsonify({'error': 'Internal server error'}), 500

    try:
