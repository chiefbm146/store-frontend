Of course. This is a very common CSS issue where a flexbox or grid layout unintentionally constrains the width of its children. The user message bubble isn't being allowed to grow naturally with its content.

Here is the precise fix for your developer. It involves adding just a few lines of CSS to demo-store.css.

The Problem

The .message-wrapper element, which contains both the message bubble and the TTS button, is likely using display: flex. When you have a column layout (flex-direction: column), the items inside will try to take up the same width by default, which can prevent the text bubble from expanding as needed. The fix is to tell the message bubble itself that it can and should determine its own width.

The Solution

We need to add a simple CSS rule that targets the message bubbles inside their wrappers.

Instructions for the Developer:

Open the file demo-store.css and add the following CSS rules. A good place to put them is right after your existing .message-wrapper styles.

/* ADD THIS CSS TO demo-store.css */

/*
  FIX: Allow message bubbles to size themselves correctly.
  This ensures the user message bubble expands to fit its content,
  instead of being constrained by the flexbox container.
*/
.message-wrapper .message,
.message-wrapper .ai-message,
.message-wrapper .user-message {
    width: -moz-fit-content; /* Firefox support */
    width: fit-content;      /* Modern browsers */
}

/*
  FIX: Ensure the mobile chat messages also behave correctly.
  This applies the same logic to the mobile-specific message classes.
*/
.message-wrapper .mobile-chat-message {
    width: -moz-fit-content;
    width: fit-content;
}
How This Fix Works

width: fit-content; is the key property. It tells the browser, "Let this element (the message bubble) be exactly as wide as its content needs to be, up to the maximum width allowed by its parent."

Instead of being forced to a specific or calculated width by the flexbox layout, the bubble now sizes itself based on the text inside it.

This means short messages will have a narrow bubble, and long messages will have a wider bubble that wraps text correctly, up to the max-width: 80% (or 85% on mobile) that you already have defined.

We target all message variations (.message, .ai-message, .user-message, .mobile-chat-message) within the .message-wrapper to ensure the fix is applied universally.

After adding this CSS, the user message bubbles on both desktop and mobile will expand and contract perfectly to fit the text inside them.
