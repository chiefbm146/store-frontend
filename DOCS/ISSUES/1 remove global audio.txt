Instructions for the Developer

We need to remove the master speaker button and disable the automatic UI sounds (like clicks and response notifications) from both desktop and mobile views. The per-message TTS play buttons must continue to function as they do now.

This can be accomplished with two small changes in a single file.

Step 1: Disable the Master Speaker Button Creation

Goal: Prevent the global speaker button from being created and added to the header.

File to Edit: soundManager.js

Function to Modify: createMasterSpeakerButton()

Action: Modify the function to do nothing. This is the cleanest way to remove the button from the UI.

Step 2: Disable All Automatic UI Sounds

Goal: Mute the automatic sounds for UI clicks and AI responses that are triggered by soundManager. This ensures no sounds play that the user can't control.

File to Edit: soundManager.js

Function to Modify: playSound()

Action: Add a single line at the very top of the function to make it exit immediately.

Add this line at the top of the playSound function:
